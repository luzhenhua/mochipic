## 麻薯图图 · MochiPic 0.0.5

- 「图片」页按住 ⌘ 点按缩略图即可多选，当前大图保持不变。
- 可点居中的「移除所选」，或向下拖到缩略图下方再松手。拖回或按 Esc 可取消。
- 移除只影响当前批次。点「撤销」或按 ⌘Z 可恢复刚移除的图片及原顺序，即使已经回到导入页。

Command-click thumbnails to select multiple images without changing the preview. Drop them below the strip to remove them from the batch, and use Undo to restore their original order. The original files are kept.

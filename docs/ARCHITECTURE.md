# 架构

麻薯图图（MochiPic）在本机运行。MyGo 提供窗口、系统文件对话框和 Finder 投放事件；Lobe MyGo 提供原生视图和主题。Go 控制状态与并发；govips 和 libvips 负责图像处理。

- `internal/imageformat`：集中登记输入扩展名、可导出格式和 macOS 文档类型；打包、扫描、选择器及名称规划共用。
- `internal/imaging`：核对文件内容、方向修正、转 sRGB、几何、水印合成和编码。常规位图、JPEG XL、JP2 由 libvips 解码；SVG 用 libvips 的 librsvg 加载器按画布大小渲染。Image I/O 解码 BMP、ICO、J2K 和 PSD 合成图；Core Image 用系统已有的解码器读取 RAW。实时预览和导出共用画布几何、文字排版、Logo 尺寸和叠放规则。
- `internal/files`：命名模板、路径检查、目标名称规划和独占提交。批处理只读源文件。
- `internal/batch`：扫描目录、文件去重、有界并发、取消与结果。
- `internal/series`：文件的帧或页计数、显式范围及解析规则。处理范围随文件保存在当前批次；预览位置不参与导出选择。
- `internal/crop`：以转正后的原图像素表示裁剪框，计算固定比例、拖动边界与对齐。手动框和固定比例规则随批次中的原图保存；预设不保存具体照片的裁剪坐标。
- `internal/certification`：内置徽标、本地自定义库、徽标组合，以及预览和导出共用的等高排列和边界。通用锚点和自由位置由 `internal/placement` 提供。
- `internal/caption`：单张图片的标题、样式、范围和输入限制；与系统界面或图像库无关。
- `internal/preview`：防抖、过期结果检查与有限大小的预览。
- `internal/app`：协调预览、规划和任务，界面在主线程读取状态。
- `internal/ui`：共享原生窗体、页级工具栏/检查器、预览与表格、键盘与系统交互。空批次走独立导入页，整窗接收文件，首批预览或缩略图就绪后进入工作台；解码失败也会进入工作台显示错误。欢迎窗与工作台共用同一原生窗口，工作台偏好尺寸与过渡尺寸分开记录。导航、缩放、平移以及错误页排除重试的选择只保留在界面会话中；失败原记录和任务账目仍由 `internal/app` 管理。
- `internal/config`：版本化的本机 JSON 偏好和预设，包括界面语言及最后一次手动调整的窗口尺寸。
- `internal/l10n`：以消息 ID 和 ICU 参数为接口，内嵌独立的 BCP 47 语言目录。批处理只保留结构化状态和错误原因，界面与菜单按当前语言显示；原文件名、用户输入和重命名模板不经过翻译。

流水线：限制输入资源 → 只读打开 → 解码并旋转 → 转 sRGB → 裁剪 → 缩放、留白 → 按最终输出坐标合成文字、Logo 和认证徽标 → 处理透明度 → 编码 → 临时文件与独占提交。设计上不读取整批的解码数据；进程只初始化一次 libvips，退出时先等待后台任务关闭，再释放运行库。

## 资源与并发

源文件以只读且不跟随末级符号链接的描述符打开。扫描检查格式头、帧页数量和起始尺寸；预览与导出会再次检查实际选中的帧或页，像素流损坏仍可能在解码时发现。长边、像素总数和裁切前的中间尺寸均有上限。libvips 在应用进程初始化一次，禁用跨图片的操作缓存；每个任务独立持有并关闭 ImageRef。用 Go Pinner 持有延迟解码缓冲，派生处理和编码完成后再解除。Image I/O 返回的 sRGB 像素由 libvips 复制，随即释放系统缓冲。文字遮罩和 Logo 有额外的尺寸限制。退出先停止后台任务和预览，再调用 libvips Shutdown。

SVG 保留向量到确定目标尺寸时再栅格化，读取缓冲不提供基础路径，外部文件与网络资源无法载入。PSD 先验证标准文件的合成图区段及 Photoshop 兼容性标记，不解析或合成图层。RAW 用登记中的类型提示识别共用 TIFF 容器的相机文件，由 Core Image 生成带正确方向的 SDR 像素；只选择系统已内置的解码版本。

GIF、WebP、TIFF 和 JPEG XL 读取指定帧或页；JPEG XL 的帧索引由 libvips 原生接口处理，因为当前 govips 没有转发该参数。APNG 按块序号、合成和清除规则重建画布，PNG 子图仍由 libvips 解码；独立封面不属于动画。动画 AVIF 和 HEIC 序列使用 Image I/O 的帧与时间信息。合并导出逐帧或逐页处理，压缩后的 WebP 帧由 libwebpmux 封装以保留时长和重复帧，TIFF 由 Image I/O 封装以保留各页的独立尺寸。合并时顺序处理且限制总像素；拆分时每个帧或页都有单独的计划项、输出名和重试身份。

批处理最多 4 个 Go 工作协程，libvips 内部每项并发为 1。较大的输入和需要完整缓冲的系统解码共用单独的并发槽；大尺寸 AVIF 编码也串行，避免几张大图同时占用内存。进度从真实工作队列聚合，最频繁每 100 ms 送一次，结束时总账满足已终结 + 进行中 + 剩余 = 总数。取消立即停止领取新项；已开始的 libvips 调用在返回或到达写入检查时停止。跨过提交边界的输出保留。

「图片」只请求原图预览。点击图片或帧页立即提交后台解码，连续编辑参数仍合并请求。有现成的同图缩略图时，原图画布先显示它，并使用清晰预览的尺寸来计算缩放；切换同一文件的帧页时保留上一个画面，直到正确的帧页就绪。常见 8 位 sRGB 预览直接从 libvips 取缩小后的像素；少数通道和位深保留原来的转换路径。原图和处理底图按文件、帧页、裁剪和尺寸缓存，最多 12 项／64 MiB 的位图。切回缓存项立即绘制，后台检查文件身份、大小和修改时间；外部更改会使缓存失效。空闲时只准备前后各一张合适的静态 JPEG／PNG／WebP；预取不挤走看过的图，也不抢占大图专用解码槽。

从 0.0.14 起，`app.Model.EditSelection` 保存跨页共享的照片选区，`Selected` 保存选区中正在预览的一张。添加其他照片到选区时保留焦点。导入后的第一张自动选中，新加入的照片从当前批次的默认设置开始。每个 `files.Source` 持有不可变的 `PhotoSettings`，保存水印、缩放、格式、命名及对应预设。裁剪区域、认证组合、标题和帧页范围也随源记录保存。界面显示焦点照片的值，并按选区检测有差异的字段。修改一个控件只向所选图片写回对应字段；尺寸锁定时按各图自己的比例联动。显式应用预设会替换其包含的整套参数。

下拖缩略图时只绘制提示与副本，在有效区域释放才提交移除。撤销可恢复原顺序、选区和逐图设置。照片选择和批次历史都保存在内存中。全批共用输出目录、同名文件策略和目录结构。规划器按各图的格式和命名规则生成路径，再在同一计划里解决跨图冲突。导出包含全部已导入图片，失败重试保留失败项的参数快照和原序号。

`internal/app/history.go` 在主线程维护当前批次的撤销游标。每步保存参数差异，批量操作只记录实际变动的图片，队列编辑按索引回放。历史最多保留 100 步，并限制持有的源记录及文本体积；不保存位图、文件副本、任务结果或导出内容。滑块和拖动手柄实时更新，松手后只记一步；一次输入焦点或选色弹窗内的连续编辑合并记录。新编辑从当前步骤分支并清除重做。应用仍用实时参数刷新相应的叠加层或后台规划；命名及同目录输出项的回放保留可见快照。导入、素材校验和导出进行时暂停回放，「新建批次」清空历史。

MyGo 在同一个画布里分别绘制水印。文字或 Logo 有内容时才启用这一层；旧预设中已关闭的内容保持关闭。拖动水印和调整不透明度直接更新绘制参数；文字内容、字体或字号变化只重画字形，Logo 缩放复用已解码的 PNG。自由位置记录水印在可移动范围内的相对位置，预览与导出共享计算规则，并适配每张成片的尺寸。九宫格可重新设置锚点。「图片」与「水印」复用同一画布；同图切换页面保留缩放和平移。裁剪框、遮罩和网格绘制在原图上方，拖动只改界面草稿。确认后，渲染器、批处理及失败重试读取每张原图的裁剪快照。多页文件按同一裁剪规则逐页计算；页尺寸不同时尽量维持相对中心和比例。

每张照片最多保存 8 枚 Logo，每枚独立持有尺寸、透明度、位置和叠放次序。导入在后台逐个验证 PNG，每个文件最多 16 MiB、400 万像素，完成后按启动导入时的选区应用。编辑按 Logo 文件路径匹配不同照片上的同一素材。批次编码器预先读取任务参考设置中的 Logo，供多个工作协程复用。照片的额外素材在相应输出中读取并随处理结束释放。拆分帧、合并动图和多页 TIFF 都按所属照片的设置处理。拼图使用最终画布的水印。旧单 Logo 预设仍可读取。

拼图预览和导出共用格子、留白、适配和素材裁剪的坐标。预览每次准备至多 16 张静态素材，每张长边上限 600 px；换序只改变这些已缓存的位图摆放。离开画布后保留当前批次的一份拼图草稿及其换序历史；素材从批次移除时暂停草稿，恢复素材后可再打开。导出按当前顺序逐张处理，完整解码图不跨素材保留，只将拟合后的格子像素留给最终画布（最多 2,400 万像素）。一份拼图的水印按整张画布定位。拼图复用导出目录和冲突策略，但使用独立的单文件规划和取消流程，仍保护本批次所有已导入原图。

蒙版标题和外观按所选照片逐字段修改，生成任务时每个输出项保存自身快照。独立预览工作协程根据照片、最终尺寸和文字排版生成字形，合并快速输入并丢弃旧结果。底色直接填充在预览上，改颜色或透明度可继续复用底图和字形。导出调用同一份 Pango 排版，在 libvips 中合成底色、标题、文字、Logo 和认证徽标。「保存样式」将外观写入本机偏好。标题保留在当前批次。

首次进入「认证」时，后台准备内置和本机自定义徽标的显示位图。修改大小、间距和位置只更新叠加层。对选区增减单枚徽标时，根据各图已有的徽标组合补齐或移除该枚。任务及重试使用各图的组合快照，按每个帧或页的成片尺寸重新排列并合成。每张图最多 10 枚。导入静态 PNG 时验证尺寸和像素，生成本机副本，最多保存 24 枚自定义徽标，以内容摘要去重并独占提交。

「格式」页在同一画布先显示当前效果，再后台编码并解码选中的画面，显示实际编码结果和大小。合并成片的总字节数不由单帧预览推算。底图、邻图预取、文字、Logo、编码预览各有固定的最近请求工作协程；只将有界的 Go 位图交给界面，过期结果不发布。名称规划和缩略图独立工作；缩略图只请求可见页，最多保留 96 项。模型仅在 MyGo 主线程更新界面状态。

「重命名」编辑命名参数，以及「输出」切换当前目录的冲突策略或保留目录结构时，上一份规划结果留在原视图中。切换立即提交，连续输入合并提交；只发布当前请求的结果。视图沿用原有的缩略图、分页和展开状态，输出路径或输入队列改变时会废弃旧预览。上一份结果仅供显示；复制等待规划完成，开始处理按最新设置独立生成并校验输出计划。

自定义拼图以照片路径标识素材，分别记录原始放置区域、可见矩形、裁剪前的源像素区域及边角样式。一次拖动使用一个历史记录组。预览从缓存位图按源矩形取样，导出使用同一几何映射从原图取样。照片按缩略图顺序叠放，导出时将边角覆盖率乘入素材自身的 alpha，再与下方画布合成。

## 输出保护

规划对输入排序并保留重试序号，用 Unicode 规范化和大小写折叠检测同名。输出根不能包含已导入的原图。扫描上级目录时排除其中的当前、默认和本次会话已用过的输出根；明确选中的文件或文件夹仍可作为输入。目录逐级用 `openat` 打开并拒绝子目录符号链接，预检写入权限。编码到独占临时文件，刷盘并复查目标目录身份后，用 macOS `RENAME_EXCL` 提交；支持硬链接的文件系统可用独占链接作为回退。两条路径都不能覆盖已存在的名称。提交瞬间若出现碰撞，则继续避让或跳过；临时文件会在返回时清理。

## 应用更新

`internal/ui/updates.go` 使用 MyGo 的原生 updater 插件。应用菜单和「关于」提供手动检查；自动检查默认关闭，可由用户开启。版本检查只读取 GitHub 的公开发布清单，不发送图片或路径。插件的 `updater.json` 保存到与应用偏好相同的本机目录，切换语言不会改变它。

打包脚本嵌入 GitHub 清单地址和 Ed25519 公钥。更新包包含已签名的完整 `.app` 及随附解码库。MyGo 下载后核对长度和签名，应用退出后才替换包；批处理或拼图导出进行中时，应用会拦截退出及更新重启。开发模式和无权写入安装位置的应用不能自行更新。[发布指南](RELEASING.md)记录构建和验收。

## Windows 适配

Windows x64 共用 MyGo／Lobe MyGo 界面和 Go 批任务。应用按平台选择快捷键和字体，并复用同一套预览和导出参数。Windows 的 BMP、ICO、PSD 合成图、J2K 和 RAW 走限制范围的本地解码。HEIF 和 AVIF 使用随包的 libheif，按序列轨道读取帧与时间。多页 TIFF 通过 libtiff 依次写入每一页，允许各页尺寸不同。

Windows 文件层以目录句柄逐级打开子目录并拒绝重解析点。目录预览用现有句柄打开同一目录，以获得独立的枚举位置并检查访问权。导出从已打开的临时文件句柄做独占重命名，目标文件名也相对于已验证的目录句柄解析，保留共享的冲突重试和取消逻辑。相机覆盖范围、文件系统行为和字体效果均需实机验收。

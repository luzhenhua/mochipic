# 麻薯图图使用指南

麻薯图图（MochiPic）是面向工业产品照片的原生批处理工具。导入、预览、处理和导出都在本机完成。队列中的原图只读，导出不会替换已有文件。

Windows x64 安装包面向 Windows 10 和 11。安装时可选择目录，完成后可从桌面或开始菜单启动。构建说明见 [Windows x64 交叉构建](DEVELOPMENT.md#windows-x64-交叉构建)，实机状态见 [Windows 验收](WINDOWS_TEST.md)。

## 安装与第一次导入

在 [Releases](https://github.com/luzhenhua/mochipic/releases/latest) 选择安装包。在 Apple Silicon Mac 上打开 DMG，把 MochiPic 拖进「应用程序」。DMG 提供六种语言，每份都附本地化安装帮助。Windows 可安装 x64 版或解压便携包。应用已包含 libvips 和所需动态库。简体中文界面显示「麻薯图图」，其他语言显示「MochiPic」。

启动时显示居中的 660 × 390 点导入窗。「选择文件夹…」右侧的箭头可以设置是否包含子文件夹。首张预览就绪后，同一窗口展开到上次的工作台大小（首次为 1120 × 720 点）。启用 macOS「减弱动态效果」后直接切换尺寸，照片叠保持静止。

1. 空批次先显示导入页。把图片或文件夹从 Finder 拖到窗口任意位置，或用「选择图片…」「选择文件夹…」。导入后自动进入工作台并预览第一张；可用左上角「导入」继续添加。扫描上级目录时会跳过其中的输出文件夹；要再次处理成片，直接选择该文件夹或文件即可。
2. 单击缩略图编辑一张，按住 ⌘ 点按可增减选区，点「全选」或在缩略图上按 ⌘A 可编辑整批。裁剪与尺寸、水印、认证、蒙版、格式和重命名共用这份选区，切页后右栏仍标明编辑张数。多张的参数不同时，界面提示「多个值」。例如，只改水印文字，两张图可以继续使用各自的字号。
3. 「图片」页预览原图，编辑页预览当前照片的效果。「格式」可看实际编码效果。每张图的修改自动保存在当前批次，可随时切回继续编辑。随后导入的照片从批次默认设置开始。关闭应用或新建批次会结束这份编辑记录，常用设置可存为本机预设。
4. 在「输出」点击目录名选择目标位置，逐行核对文件名、处理内容及尺寸。「导出全部 N 张」按各图的设置统一导出。目录、同名文件处理和保留目录结构由整批共用。处理时可取消，完成后可打开目录或按失败时的设置重试。错误页的「跳过所选」可用「恢复重试」撤销。

⌘O 导入图片，⇧⌘O 导入文件夹，⌘N 新批次，⌘0 适合窗口，⌘1 查看预览像素，⌘, 打开设置。设置和预设保存在本机；输出目录可按批次覆盖。

在「图片」页按住 ⌘ 点按缩略图可多选，大图保持不变。点居中的「移除所选」，或把缩略图往下拖到提示区再松手；拖回或按 Esc 可以取消。缩略图聚焦时也可按 ⌫。即使已经移除全部图片，导入页仍可撤销，恢复原顺序和编辑参数。

窗口顶部的「撤销」「重做」与系统「编辑」菜单共用当前批次的历史，快捷键为 ⌘Z／⌘⇧Z。悬停可查看对应操作。一次多图编辑可以一步撤销，每张图恢复自己的旧值。切页保留记录。输入框聚焦时，⌘A 和文字撤销由输入框处理，顶部撤销按钮仍操作批次。

在「设置 → 外观 → 语言」可切换简体中文、英语、日语、西班牙语、法语和葡萄牙语（巴西）。界面立即切换，下次打开沿用所选语言。添加语言和修改译文见 [CONTRIBUTING.md](../CONTRIBUTING.md)。

从 0.0.2 起，可在应用菜单或「设置 → 关于」检查更新，也可以在「关于」打开自动检查。更新由 [MochiPic Releases](https://github.com/luzhenhua/mochipic/releases) 提供；首次使用 0.0.1 的用户请手动安装新版。发布文件和验收方法见[发布指南](RELEASING.md)。

## 多 Logo 水印

在「水印 → Logo」点「添加 Logo」一次选中多张透明 PNG，也可以拖入右侧的 Logo 缩略图区。所选照片各自最多容纳 8 枚。首枚沿用空白时设置的参数，随后添加的优先放到空角。点击缩略图或画布上的 Logo 可移动、改尺寸和透明度，或用「×」移除。多选照片时，同一个 Logo 的修改会更新选区内已有该 Logo 的图片。点照片空白处可收起选框。「图层」支持拖动排序，越上方越靠前。

## 认证徽标

在「认证」页点选徽标即可加到所选照片。若只有部分照片已有该徽标，图标显示减号，点一下就能为其余选中照片补齐。显示勾号时再点一下可从选区移除该枚徽标。内置 10 枚，也可以导入本机 PNG。多枚徽标等高排列，可调大小、间距、九宫格位置，也可在画布上拖动整组。动图和多页 TIFF 按确认的帧或页合成徽标。

## 蒙版标题条

在「蒙版」输入标题，照片底部即出现通栏。默认黑底 40% 不透明度、白字居中；高度可自动随内容调整，也可按图高指定。「更多设置」可改字号、文字颜色与对齐。清空标题即可移除标题条。

例如，单击最后一张再输入「出厂实拍」，只有这张会出现标题。选中多张再改透明度，可保留各自的标题。「保存样式」用于保存本机默认外观。标题条以裁剪、缩放后的画布为准，支持选定的动图帧和 TIFF 页。拼图独立导出。

## 裁剪与拼图

- **裁剪**。进入「裁剪与尺寸」，拖动四角调整范围、拖动框内移动。可选自由、1:1、4:5、4:3 或 16:9。拖动时底图保持原样。点击「完成裁剪」后，所选照片各自保存裁剪设置，不同尺寸的图片按自身画布计算。
- **拼图**：在「图片」预览页按住 ⌘ 多选，或在列表勾选 2–16 张静态图片，点击「拼图」。默认按素材像素推荐画布并排成网格，可切换横拼、竖拼或自定义。拖动下方缩略图可换序。自定义排版保留进入时的位置。拖照片中间移动，拖四角按当前画框比例裁剪，松手后按 ⌘Z 可撤销整次拖动。右键照片选择「拉伸」可拖一侧改变宽或高。选中照片可单独设直角、圆角或倒角。可设画布大小、间距、背景和适配方式。拼图沿用已确认的单图裁剪，并在整张画布上应用当前水印。使用「格式」中的输出格式及「输出」目录；没有目录时，导出会打开文件夹选择器。要使用动图帧或 TIFF 页，可先拆分导出为单张图片，再作为拼图素材导入。

## 图片格式

- 导入 JPG、PNG、WebP、HEIC/HEIF（HEVC）、TIFF、BMP、ICO、AVIF、GIF 和 JPEG XL。ICO 使用最大的有效图标尺寸。混合导入时，可点击工作台底部的「未导入」查看文件和原因。
- 动画 GIF、WebP、APNG、JPEG XL、AVIF、HEIC 序列及多页 TIFF 都可逐帧或逐页预览。选择「全部」或「指定帧／页」并输入范围，例如 `1, 3-5`。多选时可一起修改同类文件的帧或页范围，导出前按每个文件的实际总数验证，编号沿用原文件顺序。
- 多帧可合为 WebP 动图，多页可合为 TIFF。两种都可以拆成编号单图，使用当前 JPG、PNG、WebP 或 AVIF 格式。只选一帧时合并会得到一个静态 WebP。AVIF 和 HEIC 序列的解码依赖系统支持。
- 也可导入 JPEG 2000（JP2 和 J2K 码流）、SVG、PSD 和相机 RAW。SVG 按输出尺寸转成位图，不加载外部资源。PSD 读取保存的合成图；缺少合成图时，在 Photoshop 启用「最大兼容性」后另存。RAW 支持范围随 macOS、相机型号和拍摄模式变化，见 [实测样片](RAW_COMPATIBILITY.md)。
- 预览和导出使用 sRGB 流程，输出为 8 位 SDR，不保留 HDR 增益图。输入文件最多 160 MiB（SVG 8 MiB），每帧或页最多 5,000 万像素、单边 12,000 px；PSD 合成图解码前估算上限为 512 MiB。输出每帧或页最多 2,400 万像素，合并的总像素最多 6,400 万；超出时可缩小尺寸、减少范围或拆分。每个文件最多 1,000 帧或页，每批最多 10,000 个输出文件。预览长边最多 1,400 px。

## 构建和验证

要求 Apple Silicon macOS、Go 1.27.3、Xcode SDK 及 Python 3；运行 `xcrun --show-sdk-path` 确认 Xcode 可用。项目依赖安装在 `.deps/`，首次构建会下载经过校验的公开依赖。

```sh
scripts/setup-native.sh
scripts/go.sh test ./...
scripts/go.sh vet ./...
scripts/go.sh test -race ./...
python3 scripts/package-app.py
scripts/verify-bundle.sh
```

# MochiPic Windows x64 验收

最低测试目标为 Windows 10 x64，同时验收 Windows 11 x64。记录 `winver` 显示的系统版本及使用的测试包名称。

## 一键测试

完整解压 `MochiPic-0.0.25-windows-x64-qa.zip` 到本机 NTFS 盘，用普通账户双击 `Run-Checks.cmd`。它依次运行文件安全、图像编解码、批处理、UI 逻辑及运行目录切换与清理测试，再通过便携版的启动器打开一个原生测试窗口。千图批量测试会比其他检查多花一些时间。完成后，控制台会显示日志目录。保留其中的 `summary.txt` 和对应的测试输出。

测试使用内置样图与临时文件夹。相机 RAW 需要另外准备样片。实际安装卸载、资源管理器拖放、输入法和显示缩放按下面的步骤检查。

## 离线格式验收

将 `MochiPic-0.0.25-windows-x64-format-qa.zip` 完整解压，再双击 `Run-Format-Checks.cmd`。样片和 0.0.25 的原版便携运行库都在包内。脚本先校验九个相机样片的 SHA-256，再测试 RAW 解码、方向、预览和 WebP 导出，以及动图帧时长、循环、透明度和 TIFF 页尺寸、顺序。测试还会核对原图哈希并用正式程序打开原生测试窗口。请保留 `summary.txt`、`imaging.stdout.txt` 与 `native-window.stderr.txt`。

九个相机 RAW 分别为 CR2、CR3、NEF、ARW、RAF、RW2、ORF、PEF 和 DNG，对应的文件名、源站编号与校验值见包内 `Camera-Fixtures.json`。[raw.pixls.us CC0 样片库](https://raw.pixls.us/)

## 原版安装包验收

解压 `MochiPic-0.0.25-windows-x64-install-qa.zip`。Windows 已启用 Sandbox 时，双击 `Run-In-Sandbox.cmd`，验收会在隔离桌面自动运行。也可在干净的 Windows 虚拟机或新账户双击 `Run-On-Clean-Windows.cmd`。脚本发现已存在的 MochiPic 安装、卸载注册表项目、开始菜单快捷方式或 ImageFlow 偏好目录时会停止。

验收包使用字节相同的 0.0.24 和 0.0.25 原版安装程序。依次核对覆盖升级、新目录首次安装、快捷方式和卸载记录、原生窗口、安装版 DLL 的千图批处理、占用时拒绝卸载及完成后的文件哈希。结束后保存 `installer-result.txt` 和 `installer.log`。Windows Sandbox 中只读共享验收文件，单独共享日志目录，网络关闭。系统版本、账户权限和硬件仍按实际情况记录；以下 Explorer 拖放、输入法、显示缩放等实机操作另外验收。

## 实机操作

1. 在干净的系统上运行安装包，或把便携 ZIP 完整解压后双击 `MochiPic.exe`。安装时检查「选择安装位置」页面，可试一个带中文和空格的目录。安装后从桌面和开始菜单的快捷方式分别启动，检查紧凑导入窗和退出。
2. 把 JPEG、透明 PNG 和 WebP 放进含中文及空格的文件夹。分别从资源管理器拖入图片与文件夹，测试「包含子文件夹」，确认缩略图和首张预览正常。
3. 按 Ctrl 多选，逐图裁剪和加水印，测试 Ctrl+Z 和重新打开后的工作台尺寸。检查中英文标题的字形及预览和导出位置。
4. 输出到另一个目录。分别测试同名避让、跳过、保留目录结构和取消。使用 PowerShell 的 `Get-FileHash` 比对原图及预先放在目标中的同名文件。
5. 用带方向信息的 JPEG、SVG、BMP、ICO、PSD 合成图、JPEG XL、JPEG 2000、RAW、GIF、WebP、AVIF、HEIC 和多页 TIFF 逐项记录结果。对动图确认末帧、帧延迟和透明度。对多页 TIFF 确认页数、页尺寸和顺序。记录所有失败样图的格式、扩展名和错误提示。
6. 将应用语言切到英语或日语，核对导入页底部的本地处理说明。导入无法解码的 RAW 时，提示应指出文件或拍摄模式可能不受支持。
7. 另用一份干净测试环境安装 0.0.24，关闭应用，在安装目录下放一份测试图片，再运行 0.0.25 安装包。检查「关于」为 0.0.25，确认旧安装路径下的测试原图内容和位置一致。
8. 从 Windows「已安装的应用」卸载。应用运行时先确认卸载会提示关闭应用。关闭后重新卸载，确认桌面及开始菜单的应用快捷方式与归属明确的运行文件已移除，原图、导出文件及用户偏好仍在。0.0.20 及更早版本的运行目录还没有文件归属清单，因此保留。

当前本地验收包尚未做 Authenticode 签名。「设置 → 关于 → 检查更新」需等正式的 Windows 更新清单上线后才能连接公开更新。Windows 10 和 11 的实机结果待记录。

## 开发用离线更新验收

`MochiPic-0.0.25-windows-x64-safe-update-qa.zip` 中的 `Run-Update-Checks.cmd` 使用临时安装副本和本机回环地址上的更新源。验收程序运行与试用版同源的启动器，验证拒绝篡改归档和版本不匹配、安装签名新版、拒绝重复安装并打开原生窗口。最后验证占用时拒绝清理，退出后根据文件哈希移除两代程序文件，保留两处测试原图和修改过的配置。

日志中的 `TestWindowsSignedUpdate` 应显示 PASS。旧的 `-update-qa.zip` 用于复现 MyGo 整目录替换问题。日常试用使用安装包和一键测试包。
